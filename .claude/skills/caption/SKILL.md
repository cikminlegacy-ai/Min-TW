# /caption — caption siap post

Input: topik / skrip / transcript / link / nama projek (cth `tq1`). Kalau nama projek: baca `projects/<nama>/DESIGN.md` + transcript/cuts untuk isi sebenar dan kredit muzik.
Jawab dalam Bahasa Melayu rojak santai (aku/kau). Jangan tanya soalan.

Baca dulu: `.claude/skills/edit-video/funnels.md` (funnel, BANK CTA WHAT'S NEXT, larangan).

## Output
Satu baris: "Funnel X — poin utama: …"

**3 pilihan caption** (gaya berbeza), setiap satu siap copy-paste:
1. **Pendek & padu** — 1–2 baris, baris pertama = hook (nampak sebelum "…more").
2. **Cerita** — 3–5 baris pendek: hook → konflik/poin → ajak tonton habis.
3. **Senarai** — hook + 3 poin bernombor/✓ ringkas + soalan.

Setiap caption:
- Baris pertama ≤ 70 aksara, buat orang tekan "more".
- Emoji maksimum 2–3, relevan (bukan hiasan penuh).
- Tutup dengan **CTA What's Next** ikut funnel (dari bank funnels.md, satu CTA sahaja: komen / follow / save / link bio).
- Soalan untuk naikkan komen bila sesuai ("Kau nombor berapa?").

Lepas tu:
- **5 hashtag**: 2 luas (#fyp-tahap topik, cth #belajarquran), 2 niche (#tajwid), 1 jenama/siri user kalau ada. Huruf kecil, tiada hashtag spam.
- **Kredit** kalau video guna muzik/SFX CC BY: baris "Music: <tajuk> — <artis> (CC BY)" / "SFX: Google Sound Library (CC BY 4.0)".
- **⭐ Pilihan aku: Caption #N** + sebab satu ayat.

## Peraturan
- Bahasa orang biasa, analogi Malaysia, tiada ayat korporat.
- Edukasi jangan hardsell; tiada janji kaya cepat / claim tak realistik.
- Topik agama/Quran: sopan, tepat, tiada clickbait mengelirukan.
